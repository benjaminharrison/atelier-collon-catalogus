# atelier-collon-catalogus

Bevat de Atelier Collón productcatalogus, gepubliceerd via GitHub Pages onder
het subdomein `catalogus.ateliercollon.com`. De PDF is opgenomen zodat
iOS Safari de native PDF-viewer kan tonen met `catalogus.ateliercollon.com`
in de URL-balk.

Publieke URL's:
- https://catalogus.ateliercollon.com/2026.pdf — directe link voor de QR
- https://catalogus.ateliercollon.com/ — fallback (HTML → 2026.pdf)
